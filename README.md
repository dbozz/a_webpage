# a_webpage

This repository contains a simple static website ready for GitHub Pages.

## Files

- `index.html` — the main webpage
- `styles.css` — styling for layout and responsive design
- `script.js` — small interactive behavior for mobile navigation and year update

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open the **Pages** section.
3. Choose the branch you want to publish from, typically `main` or `gh-pages`.
4. Set the folder to `/ (root)` and save.
5. Visit the published URL shown in the Pages settings.

## Preview locally

Open `index.html` in your browser, or use a local server if you prefer:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Change the page title and content in `index.html`.
- Adjust colors, spacing, and typography in `styles.css`.
- Add new features or sections as needed in `script.js`.
